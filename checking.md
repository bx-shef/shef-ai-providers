# Как проверить и что делать с ошибками

## Проверка

1. **Общие настройки → вкладка «Движок»:** у «Распознавания речи» и «Текста» выбрано «OpenAI-совместимое API». «Заглушка» — тестовый режим без модели: он отвечает фиксированной фразой «[заглушка shef.toolsai]» и в сеть не ходит.
2. **Расход и включение:** в блоке «Куда уходят запросы» видны адрес и модель каждого направления. Нажмите «Проверить и включить» и прочитайте отчёт.
3. Сделайте пробный запрос: вопрос AI-помощнику или звонок.
4. В «Последних запросах» должна появиться строка со статусом SUCCESS. Если запрос не прошёл, причина — в колонке «Ошибка или пометка».

Ключ и модель можно проверить и без shef.toolsai, запросом с сервера портала (для администратора):

```bash
curl -sS "АДРЕС/chat/completions" \
  -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"model":"ИМЯ_МОДЕЛИ","messages":[{"role":"user","content":"Ответь одним словом: привет"}]}'
```

`АДРЕС`, `ИМЯ_МОДЕЛИ` и откуда взять ключ — на странице провайдера. Ответ с кодом 200 и текстом ответа — всё работает. Ключ в команде остаётся в истории оболочки: после проверки очистите её или передайте ключ через переменную окружения.

## Частые ошибки

| Код | Что значит | Что делать |
|---|---|---|
| 401, 403 | ключ неверный или не имеет доступа к модели | создайте ключ заново, вставьте без пробелов; проверьте, что у ключа есть доступ к выбранной модели |
| 402 или «нет средств» | на счёте закончились деньги или лимит | пополните счёт в кабинете провайдера |
| 404 | неверный адрес или имя модели | сверьте со страницей провайдера: адрес и имя пишутся точно |
| 400, 422 | неверные параметры запроса | проверьте поле «Дополнительные параметры модели текста (JSON)»: там должен быть текст в фигурных скобках, например `{"temperature": 0.2}`, или пусто |
| 429 | слишком много запросов | подождите и повторите |
| 500, 503 | сбой у провайдера | повторите позже |

Ошибки, которые бывают только у одного провайдера, описаны на его странице.

## Если провайдера нет в списке («Свой адрес»)

Поля называются по направлению: у «Текста» — «Адрес API текста», «Модель текста», «Ключ API текста»; у «Распознавания» — «Адрес API распознавания», «Модель распознавания», «Ключ API распознавания». Ключ впишите в поле своего направления.

Расход по моделям «Своего адреса» в квоту модуля не попадает, пока в настройках направления не вписаны цены в валюте квоты (поле «Валюта квоты и расхода» на вкладке «Общие»).
