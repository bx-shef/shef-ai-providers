# Распознавание звонков

Чтобы shef.toolsai писал резюме звонка, заполнял поля сделки и оценивал разговор, запись нужно превратить в текст.

**Мы ставим вам на сервер сервис распознавания.** Внутри — faster-whisper, раздельное распознавание менеджера и клиента по каналам стереозаписи, очередь записей и отсечение тишины. Распознавание бесплатное.

## Что это даёт

- Записи звонков остаются у вас: сервис работает на вашем сервере рядом с порталом.
- Платить провайдеру за каждую минуту записи не нужно.
- Длинные звонки (до двух часов) распознаются по частям.
- Если запись стереофоническая, в тексте видно, кто говорит: менеджер или клиент.

## Как подключить

Установку выполняем мы. После установки в shef.toolsai:

**Общие настройки → «API» → направление «Распознавание»:** провайдер «Свой адрес» и

| Поле | Значение |
|---|---|
| Адрес API | `http://127.0.0.1:8000/v1` |
| Модель | имя модели, которое укажем при установке |
| Ключ | ключ сервиса, который задаём при установке |
| Таймаут | 1800 секунд (длинные записи на процессоре распознаются не мгновенно) |

Затем в блоке «Движок» нажмите «Выбрать движок модуля: оба» или «только распознавание» и проверьте работу — [как проверить](checking.md).

Адрес `127.0.0.1` значит, что сервис доступен только с самого сервера. Не открывайте его порт в интернет.

## Когда распознавание нужно у облачного провайдера

Распознавание звонков также есть у [BitrixGPT Вайбкод](providers/bitrixgpt.md). У DeepSeek, hoster AI studio и Яндекса распознавания речи в этом каталоге нет — для звонков используйте сервис на вашем сервере или BitrixGPT.
