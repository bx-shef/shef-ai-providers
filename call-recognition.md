# Распознавание звонков

Чтобы shef.toolsai писал резюме звонка, заполнял поля сделки и оценивал разговор, запись нужно превратить в текст.

**Мы ставим вам на сервер сервис распознавания: faster-whisper, раздельное распознавание менеджера и клиента, очередь записей, отсечение тишины. Распознавание бесплатное.**

## Что это даёт

- Записи звонков остаются у вас: сервис работает на вашем сервере рядом с порталом.
- Длинные звонки (до двух часов) распознаются.
- Если запись стереофоническая, в тексте видно, кто говорит: менеджер или клиент.

## Как подключить

Установку выполняем мы: напишите нам, и мы поставим сервис. После установки:

1. **Общие настройки → вкладка «Движок»:** у «Распознавания речи» выберите «OpenAI-совместимое API».
2. **Вкладка «Провайдер» → направление «Распознавание»**, провайдер «Свой адрес»:

| Поле | Значение |
|---|---|
| Адрес API распознавания | `http://127.0.0.1:8000/v1` |
| Модель распознавания | имя, которое укажем при установке |
| Ключ API распознавания | ключ сервиса, который задаём при установке |
| Таймаут распознавания, секунд | 1800 |

3. **Расход и включение → «Проверить и включить»**, затем **«Движок» → «Выбрать движок модуля: оба»** (или «только распознавание») — [как проверить](checking.md).

Адрес `127.0.0.1` работает только внутри сервера — так и оставьте.
