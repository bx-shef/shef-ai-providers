# BitrixGPT Вайбкод

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Изображения на входе | да, у `bitrixgpt-5.5`, `bitrixgpt-5.5-thinking`, `bitrixgpt-6.0-agent` |
| Распознавание звонков | да |

Модели работают в облаке Битрикс24 по OpenAI-совместимому API. Контекст у новых моделей — до миллиона токенов.

## 1. Что нужно заранее

- Портал подключён к Вайбкод (в коробке — модуль «Интеграция с Битрикс24 Вайбкод»), задан внешний адрес портала.
- Личный ключ Вайбкод. Ключ приложения без токена сессии не подходит.
- Условия расхода — на странице [vibecode.bitrix24.tech/ai-models](https://vibecode.bitrix24.tech/ai-models): часть моделей расходует AI-квоту тарифа портала, агентные оплачиваются отдельно с баланса Вайбкод. Сверьтесь со страницей перед выбором.

## 2. Что вписать

**Общие настройки → «API»**

Направление «Текст», **выбор из списка**: провайдер BitrixGPT, модель из списка, ключ Вайбкод.

Направление «Текст», **свежие агентные модели** (в списке пока нет — вписываются вручную): провайдер «Свой адрес» и

| Поле | Значение |
|---|---|
| Адрес API | `https://vibecode.bitrix24.tech/v1` |
| Модель | `bitrix/bitrixgpt-5.6-agent` или `bitrix/bitrixgpt-6.0-agent` |
| Ключ | ключ Вайбкод |

Направление «Распознавание»: провайдер BitrixGPT, модель `bitrix/deepdml/faster-whisper-large-v3-turbo-ct2`, ключ Вайбкод. Затем в блоке «Движок» нажмите «Выбрать движок модуля: оба» (или «только распознавание»).

## 3. Какую модель брать

| Модель | Для чего |
|---|---|
| `bitrix/bitrixgpt-5.5` | каждодневная работа: резюме, помощник, анализ |
| `bitrix/bitrixgpt-5.5-thinking` | сложные случаи, где нужно рассуждение |
| `bitrix/bitrixgpt-5.6-agent` | агентные задачи и очень длинный контекст (до 1 млн токенов) |
| `bitrix/bitrixgpt-6.0-agent` | самая новая; контекст до 1 млн токенов, понимает изображения |
| `bitrix/google/gemma-4-26B-A4B-it` | открытая модель Gemma 4 на стороне Вайбкод |
| `bitrix/bitrixgpt-5.6-transcribe` | распознавание звонков (второй вариант) |

Полный список — на странице [моделей Вайбкод](https://vibecode.bitrix24.tech/ai-models).

## 4. Особенности

- Ключ принимается и как `Authorization: Bearer`, и как заголовок `X-Api-Key`.
- Агентные модели и «thinking» сначала рассуждают, потом отвечают; ответ может идти дольше.

## 5. Проверка и ошибки

См. [как проверить и что делать с ошибками](../checking.md). Только у Вайбкод: 401 и 403 — ещё и когда используется ключ приложения вместо личного или портал не подключён к Вайбкод; сообщение о квоте — исчерпана AI-квота портала.
