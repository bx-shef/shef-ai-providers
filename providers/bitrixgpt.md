# BitrixGPT Вайбкод

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Понимает картинки | да, `bitrixgpt-5.5`, `bitrixgpt-5.5-thinking`, `bitrixgpt-6.0-agent` |
| Распознавание звонков | да |

Вайбкод — сервис моделей Битрикс24; запросы уходят в его облако. Контекст у моделей 5.6 и 6.0 — до миллиона токенов, у 5.5 — около 262 тысяч.

## 1. Что нужно и где взять ключ

- Портал подключён к Вайбкод (модуль «Интеграция с Битрикс24 Вайбкод») и в нём указан внешний адрес портала.
- Нужен **личный ключ** Вайбкод (не ключ приложения).
- Условия расхода — на странице [vibecode.bitrix24.tech/ai-models](https://vibecode.bitrix24.tech/ai-models): сверьтесь с ней перед выбором модели.

## 2. Что вписать

1. **Общие настройки → вкладка «Движок»:** у «Текста» и «Распознавания речи» выберите «OpenAI-совместимое API».
2. **Вкладка «Провайдер»:**

**Текст, модель из списка.** Провайдер BitrixGPT (Битрикс24 Вайбкод), модель из списка, «Ключ API текста» — ключ Вайбкод.

**Текст, модели 5.6 и 6.0.** Их нет в выпадающем списке, они вписываются вручную: провайдер «Свой адрес» и

| Поле | Значение |
|---|---|
| Адрес API текста | `https://vibecode.bitrix24.tech/v1` |
| Модель текста | `bitrix/bitrixgpt-5.6-agent` или `bitrix/bitrixgpt-6.0-agent` |
| Ключ API текста | ключ Вайбкод |

**Распознавание.** Провайдер BitrixGPT, модель `bitrix/deepdml/faster-whisper-large-v3-turbo-ct2`, «Ключ API распознавания» — ключ Вайбкод. Модель `bitrix/bitrixgpt-5.6-transcribe` вписывается вручную в «Модель распознавания».

3. **Расход и включение → «Проверить и включить»**, затем **«Движок» → «Выбрать движок модуля: оба»**.

## 3. Какую модель брать

| Модель | Для чего |
|---|---|
| `bitrix/bitrixgpt-5.5` | каждодневная работа: резюме, помощник, анализ |
| `bitrix/bitrixgpt-5.5-thinking` | сложные случаи, где нужно рассуждение |
| `bitrix/bitrixgpt-5.6-agent` | длинные цепочки шагов и очень большой контекст |
| `bitrix/bitrixgpt-6.0-agent` | самая новая; большой контекст, понимает картинки |
| `bitrix/google/gemma-4-26B-A4B-it` | модель Gemma 4, работает у Вайбкод |

Агентные модели сами выполняют цепочку шагов; для резюме звонков обычно хватает `bitrixgpt-5.5`. Полный список — на странице [моделей Вайбкод](https://vibecode.bitrix24.tech/ai-models).

## 4. Особенности

- Модели «thinking» и агентные сначала рассуждают, потом отвечают: ответ может идти дольше.
- У моделей, вписанных вручную («Свой адрес»), расход в квоту модуля не идёт, пока в настройках направления не вписаны цены.

## 5. Если что-то не работает

См. [как проверить и что делать с ошибками](../checking.md). Только у Вайбкод:
- 401 и 403 — используется ключ приложения вместо личного или портал не подключён к Вайбкод;
- сообщение о квоте — закончилась AI-квота портала.
