# DeepSeek

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Понимает картинки | да, `deepseek-flash` |
| Распознавание звонков | через [сервис на вашем сервере](../call-recognition.md) или BitrixGPT |

Контекст у обеих моделей — до миллиона токенов. Данные при работе уходят на серверы DeepSeek.

## 1. Где взять ключ

Создайте ключ на странице [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) и пополните счёт в кабинете. Ключ показывается один раз — сохраните его.

## 2. Что вписать

1. **Общие настройки → вкладка «Движок»:** у «Текста» выберите «OpenAI-совместимое API».
2. **Вкладка «Провайдер» → направление «Текст»:**

| Поле | Что выбрать или вписать |
|---|---|
| Провайдер | DeepSeek |
| Модель | основная (`deepseek-flash`) или мощная (`deepseek-v4-pro`) |
| Ключ API текста | ключ DeepSeek |
| Адрес API текста | оставьте пустым |

«Анализ сделок» и «Чат AI-помощника» без своих настроек используют «Текст».

3. **Расход и включение → «Проверить и включить»**, затем **«Движок» → «Выбрать движок модуля: оба»**.

## 3. Какую модель брать

- `deepseek-flash` — для каждодневной работы: резюме звонков, ответы помощника, анализ сделок.
- `deepseek-v4-pro` — когда нужен самый вдумчивый разбор: длинные переписки, сложные сделки.

## 4. Особенности

- Модель «думает» перед ответом; это занимает время и входит в расход.
- В «Расходе и включении» виден блок «Баланс DeepSeek» с остатком на счёте.

## 5. Если что-то не работает

См. [как проверить и что делать с ошибками](../checking.md). Только у DeepSeek: **402** — на счёте нет денег, пополните его в кабинете.
