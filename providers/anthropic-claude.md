# Claude (Anthropic)

Возможности: текст. Распознавания в каталоге нет: слой совместимости не принимает аудио (запрос с `input_audio` или файлом отвергается).

## Ключ

Ключ создаётся в консоли: [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys). Личный ключ или ключ сервисного аккаунта без привязки к рабочей области требует заголовок `anthropic-workspace-id` — сверить на странице провайдера. Страница цен: [platform.claude.com/docs/en/about-claude/pricing](https://platform.claude.com/docs/en/about-claude/pricing).

## Адрес и модель

| Поле | Значение |
|---|---|
| Адрес API | `https://api.anthropic.com/v1` |
| Модели каталога | `claude-haiku-5-5` (быстрая), `claude-sonnet-5-5` (основная), `claude-opus-5-5` (мощная) |

Адрес и имена моделей подтверждены на странице [OpenAI SDK compatibility](https://platform.claude.com/docs/en/api/openai-sdk) 2026-11-10. Anthropic называет этот слой средством для проб и сравнения, а не для промышленной работы.

## Поля shef.toolsai

Направление «Текст»: провайдер Claude (Anthropic), модель, ключ в поле ключа направления.

## Как проверить

1. Сохраните настройки. Способ выбран «OpenAI-совместимое API», а не «Заглушка».
2. «Расход и включение» → «Проверить и включить»: отчёт показывает адрес, модель и наличие ключа.
3. Сделайте пробный запрос. В «Последних запросах» появляется строка со статусом SUCCESS, токенами и стоимостью; ошибка — в колонке «Ошибка или пометка».
4. Валюта квоты одна на все направления; не совпала с валютой провайдера — расход по каталогу 0, отчёт предупреждает.

## Типичные ошибки

| Код | Причина | Что делать |
|---|---|---|
| 401 | ключ неверный | пересоздайте ключ |
| 429 | лимит частоты | подождите; лимиты — на странице провайдера |
| нет денег | на счёте нет средств | пополните счёт в консоли |
| 400 json_object | слой принимает только `json_schema` со `strict: true`; `json_object` и `text` отвергает | модуль повторяет запрос без `response_format` и разбирает JSON из ответа сам |
| 400 из-за параметров | `n` не 1; у новых моделей `temperature` ниже 1 | не задавайте эти параметры в «Доп. параметры модели текста» |
