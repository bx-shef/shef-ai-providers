# hoster AI studio

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Изображения на входе | да, по описанию провайдера |
| Распознавание звонков | нет: для него используйте [распознавание на своём сервере](../call-recognition.md) или BitrixGPT |

Облачный сервис белорусского хостера hoster.by: модели с открытыми весами работают на серверах в Беларуси. Провайдер заявляет соответствие белорусскому законодательству и возможность использования в инфраструктурах, аттестованных по Приказу ОАЦ №66.

Модели: Qwen3.8 (27b, рассчитана на работу с AI-агентами), Qwen3.6 (35b-a3b, универсальная, контекст до 262 тыс. токенов), Gemma 4 (31b, универсальная, контекст до 256 тыс. токенов).

## 1. Где взять ключ

1. На странице [hoster.by/service/cloud/ai](https://hoster.by/service/cloud/ai/) нажмите «Запустить AI» и войдите в личный кабинет.
2. Подключите услугу: «Тестировать бесплатно» (пробный стартовый баланс) или «Подключить» с пополнением счёта.
3. В кабинете в разделе hoster AI studio создайте **API-ключ** и выберите модели, к которым он даёт доступ.
4. Скопируйте ключ и точное имя модели (в кабинете рядом с ними есть кнопка копирования).

Подробно у провайдера: [как подключить услугу](https://hoster.by/help/hoster-ai/kak-podklyuchit-uslugu-hoster-ai-studio/), [как подключиться к модели по API](https://hoster.by/help/hoster-ai/kak-podklyuchitsya-k-ai-modeli-po-api/).

## 2. Что вписать

В списке провайдеров hoster AI studio пока нет, поэтому подключается как «Свой адрес».

**Общие настройки → «API» → направление «Текст»:** провайдер «Свой адрес» и

| Поле | Значение |
|---|---|
| Адрес API | `https://ai.hoster.by/v1` |
| Модель | имя модели из кабинета (например, `qwen3.6-35b-a3b`) |
| Ключ | API-ключ из кабинета |

## 3. Какую модель брать

- Qwen3.6 35b — универсальная, длинный контекст: хороший выбор для резюме звонков и анализа сделок.
- Gemma 4 — универсальная, для текстов и анализа больших объёмов данных.
- Qwen3.8 — когда нужна работа в роли AI-агента.

## 4. Особенности

- Оплата по токенам. Актуальные условия — на странице провайдера.
- Точные имена моделей берутся в кабинете, на публичной странице их нет — сверяйте при создании ключа.
