# hoster AI studio

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Понимает картинки | да |
| Распознавание звонков | через [сервис на вашем сервере](../call-recognition.md) или BitrixGPT |

Облачный сервис белорусского хостера hoster.by: открытые модели работают на серверах в Беларуси. Провайдер сообщает, что сервис соответствует законодательству Беларуси о защите информации.

Модели: Qwen3.8, Qwen3.6, Gemma 4.

## 1. Где взять ключ

1. На странице [hoster.by/service/cloud/ai](https://hoster.by/service/cloud/ai/) нажмите «Запустить AI» и войдите в личный кабинет.
2. Подключите услугу: «Тестировать бесплатно» или «Подключить» с пополнением счёта.
3. В кабинете в разделе hoster AI studio создайте **API-ключ** и выберите модели, к которым он даёт доступ.
4. Скопируйте ключ и точное имя модели (рядом с ними в кабинете есть кнопка копирования).

Подробно у провайдера: [как подключить услугу](https://hoster.by/help/hoster-ai/kak-podklyuchit-uslugu-hoster-ai-studio/), [как подключиться к модели по API](https://hoster.by/help/hoster-ai/kak-podklyuchitsya-k-ai-modeli-po-api/).

## 2. Что вписать

hoster AI studio подключается как «Свой адрес».

1. **Общие настройки → вкладка «Движок»:** у «Текста» выберите «OpenAI-совместимое API».
2. **Вкладка «Провайдер» → направление «Текст»**, провайдер «Свой адрес»:

| Поле | Значение |
|---|---|
| Адрес API текста | `https://ai.hoster.by/v1` |
| Модель текста | имя модели из кабинета (пример: `qwen3.6-35b-a3b`) |
| Ключ API текста | API-ключ из кабинета |

3. Впишите цены направления в валюте квоты, если нужен учёт расхода в модуле: у «Своего адреса» цены каталога не подставляются.
4. **Расход и включение → «Проверить и включить»**, затем **«Движок» → «Выбрать движок модуля: оба»**.

## 3. Какую модель брать

- Qwen3.6 — универсальная, контекст до 262 тысяч токенов: резюме звонков, анализ сделок.
- Gemma 4 — универсальная, контекст до 256 тысяч токенов: тексты, анализ больших объёмов.
- Qwen3.8 — когда нужна работа в роли AI-агента.

Имена моделей, кроме приведённого примера, берите в кабинете.
