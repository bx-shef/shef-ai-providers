# Яндекс (Yandex AI Studio)

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Понимает картинки | да, Qwen3.6 35B |
| Распознавание звонков | через [сервис на вашем сервере](../call-recognition.md) или BitrixGPT |

Модели работают в облаке Yandex Cloud.

## 1. Где взять ключ и ID каталога

1. В консоли Yandex Cloud создайте сервисный аккаунт с ролью `ai.languageModels.user`.
2. Создайте для него **API-ключ**.
3. Возьмите **ID каталога** Yandex Cloud, в котором работает аккаунт.
4. Убедитесь, что платёжный аккаунт пополнен.

## 2. Что вписать

1. **Общие настройки → вкладка «Движок»:** у «Текста» выберите «OpenAI-совместимое API».
2. **Вкладка «Провайдер» → направление «Текст»:**

| Поле | Что выбрать или вписать |
|---|---|
| Провайдер | Яндекс (Yandex AI Studio) |
| Модель | быстрая, основная или мощная — из списка |
| Ключ API текста | API-ключ сервисного аккаунта |
| ID каталога Yandex Cloud | ID каталога |

Без ID каталога модель не работает; в отчёте проверки появится предупреждение.

Если нужной модели в списке нет, выберите провайдера «Свой адрес» и впишите:

| Поле | Значение |
|---|---|
| Адрес API текста | `https://ai.api.cloud.yandex.net/v1` |
| Модель текста | `gpt://ID_КАТАЛОГА/имя-модели` |
| Ключ API текста | API-ключ сервисного аккаунта |

3. **Расход и включение → «Проверить и включить»**, затем **«Движок» → «Выбрать движок модуля: оба»**.

## 3. Какую модель брать

Актуальный список — на странице Яндекса: [доступные генеративные модели](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models). Имя записывается как `gpt://ID_КАТАЛОГА/…`:

| Модель | Имя после ID каталога | Контекст, токенов | В списке модуля |
|---|---|---|---|
| Alice AI LLM Flash (быстрая) | `aliceai-llm-flash` | 64 тыс. | да |
| Alice AI LLM (основная) | `aliceai-llm` | 128 тыс. | да |
| YandexGPT Pro 5.1 (мощная) | `yandexgpt-5.1` | 32 тыс. | да |
| DeepSeek V4.1 Flash | `deepseek-v4.1-flash` | 1 млн | нет, «Свой адрес» |
| Qwen3.6 35B (с картинками) | `qwen3.6-35b-a3b` | 256 тыс. | нет, «Свой адрес» |

Модели YandexGPT Lite 5 и DeepSeek V4 Flash Яндекс отключает 15 ноября 2026; выбирайте модели из таблицы.

## 4. Особенности

- Яндекс считает расход в рублях: в настройках квоты shef.toolsai (поле «Валюта квоты и расхода», вкладка «Общие») выберите RUB, иначе расход не считается.
- Моделям «Своего адреса» цены каталога не подставляются: впишите цены направления, если нужен учёт расхода.
- Если вы передаёте конфиденциальные данные, в Yandex AI Studio можно выключить сохранение запросов.

## 5. Если что-то не работает

См. [как проверить и что делать с ошибками](../checking.md). Только у Яндекса:
- 403 — у сервисного аккаунта нет роли `ai.languageModels.user` или указан другой каталог;
- `not_configured` — не заполнен ID каталога.
