# Яндекс (Yandex AI Studio)

| Что умеет | |
|---|---|
| Текст (резюме, анализ сделок, чат помощника) | да |
| Изображения на входе | да, у модели Qwen3.6 35B |
| Распознавание звонков | нет: для него используйте [распознавание на своём сервере](../call-recognition.md) или BitrixGPT |

Модели работают в облаке Yandex Cloud через OpenAI-совместимый API.

## 1. Где взять ключ и ID каталога

1. В Yandex Cloud создайте сервисный аккаунт с ролью `ai.languageModels.user`.
2. Создайте для него **API-ключ**.
3. Возьмите **ID каталога** Yandex Cloud, в котором работает аккаунт.
4. Убедитесь, что платёжный аккаунт пополнен.

## 2. Что вписать

**Общие настройки → «API» → направление «Текст»:**

| Поле | Что выбрать или вписать |
|---|---|
| Провайдер | Яндекс |
| Модель | быстрая, основная или мощная — из списка |
| Ключ | API-ключ сервисного аккаунта |
| ID каталога Yandex Cloud | ID каталога (подставляется в имя модели) |

Без ID каталога запрос не уходит, а в отчёте появляется предупреждение.

Если нужная модель в списке не показана, выберите «Свой адрес» и впишите:

| Поле | Значение |
|---|---|
| Адрес API | `https://ai.api.cloud.yandex.net/v1` |
| Модель | `gpt://ID_КАТАЛОГА/имя-модели` |
| Ключ | API-ключ сервисного аккаунта |

## 3. Какую модель брать

Список актуальных моделей — на странице Яндекса: [доступные генеративные модели](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models). Имя модели записывается как `gpt://ID_КАТАЛОГА/…`:

| Модель | Имя после ID каталога |
|---|---|
| Alice AI LLM Flash (быстрая, 64 тыс. токенов) | `aliceai-llm-flash` |
| Alice AI LLM (основная, 128 тыс.) | `aliceai-llm` |
| YandexGPT Pro 5.1 (мощная, 32 тыс.) | `yandexgpt-5.1` |
| DeepSeek V4.1 Flash (1 млн) | `deepseek-v4.1-flash` |
| Qwen3.6 35B (256 тыс., с изображениями) | `qwen3.6-35b-a3b` |

Модели YandexGPT Lite 5 и DeepSeek V4 Flash Яндекс отключает 15 ноября 2026 — используйте указанные выше замены.

## 4. Особенности

- Яндекс считает расход в рублях. Если валюта квоты в shef.toolsai другая, расход по каталогу будет нулевым — задайте валюту квоты RUB или впишите цены вручную.
- На странице Яндекса можно отключить протоколирование запросов, если вы передаёте конфиденциальные данные.

## 5. Проверка и ошибки

См. [как проверить и что делать с ошибками](../checking.md). Только у Яндекса: 403 — у сервисного аккаунта нет роли `ai.languageModels.user` или указан другой каталог; `not_configured` — не заполнен ID каталога.
