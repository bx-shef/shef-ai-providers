# Яндекс (YandexGPT, Yandex AI Studio)

Возможности: текст. Распознавание речи у Яндекса — отдельный сервис SpeechKit, в каталоге его нет.

## Ключ и ID каталога

1. В Yandex Cloud создайте сервисный аккаунт с ролью `ai.languageModels.user`.
2. Создайте для него API-ключ.
3. Возьмите ID каталога Yandex Cloud, в котором работает аккаунт.

Цены и модели: [aistudio.yandex.ru/docs/ru/ai-studio/pricing](https://aistudio.yandex.ru/docs/ru/ai-studio/pricing), [список моделей](https://aistudio.yandex.ru/docs/ru/ai-studio/concepts/generation/models).

## Адрес и модель

| Поле | Значение |
|---|---|
| Адрес API | `https://ai.api.cloud.yandex.net/v1` (прежний `llm.api.cloud.yandex.net/v1` модуль тоже узнаёт); на странице моделей адрес не назван — сверить на странице провайдера |
| Модели каталога | `gpt://<ID каталога>/aliceai-llm-flash` (быстрая), `gpt://<ID каталога>/aliceai-llm` (основная), `gpt://<ID каталога>/yandexgpt-5.1` (мощная) |

URI моделей и размеры контекста подтверждены на странице моделей 2026-11-10. YandexGPT Lite 5 в каталог не входит: страница моделей называет дату её отключения — 15.11.2026.

## Поля shef.toolsai

Направление «Текст»: провайдер Яндекс, модель, ключ — API-ключ сервисного аккаунта, плюс поле «ID каталога Yandex Cloud». ID подставляется в имя модели. Без ID запрос не уходит (ошибка `not_configured`).

Яндекс считает в рублях. Если валюта квоты shef.toolsai — USD, задайте валюту квоты RUB или впишите цены направления вручную.

## Как проверить

1. Сохраните настройки. Способ выбран «OpenAI-совместимое API», а не «Заглушка».
2. «Расход и включение» → «Проверить и включить»: отчёт показывает адрес, модель и наличие ключа; без ID каталога — предупреждение.
3. Сделайте пробный запрос. В «Последних запросах» появляется строка со статусом SUCCESS, токенами и стоимостью; ошибка — в колонке «Ошибка или пометка».

## Типичные ошибки

| Код | Причина | Что делать |
|---|---|---|
| 401 | ключ неверный | пересоздайте API-ключ сервисного аккаунта |
| 403 | у аккаунта нет роли `ai.languageModels.user` или указан другой каталог | выдайте роль на нужный каталог |
| 429 | лимит частоты | подождите; лимиты — на странице провайдера |
| нет денег | платёжный аккаунт не пополнен | пополните в Yandex Cloud |
| `not_configured` | не заполнен ID каталога | впишите ID каталога |
| json_object | зависит от модели | при отказе модуль повторяет запрос без `response_format` |
