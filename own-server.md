# Свой сервер

shef.toolsai ходит к любому серверу с OpenAI-совместимым API: `POST {адрес}/chat/completions` для текста и `POST {адрес}/audio/transcriptions` для распознавания. Подходят vLLM, Ollama, LocalAI, faster-whisper и whisper.cpp в режиме сервера, прокси.

В «Общих настройках», вкладка «API», у направления выберите «Свой адрес» и заполните поля «Адрес API», «Модель», ключ, таймаут, цены.

## Распознавание (whisper)

- Сервер отдаёт `POST /v1/audio/transcriptions` (multipart) и ответ в формате `verbose_json` с полями `text`, `duration`, по возможности `segments`. По `duration` и `speech_duration` считается расход.
- Направление «Распознавание»: адрес `http://127.0.0.1:8000/v1` (порт ваш), модель — как её называет сервер, ключ пусто (или ключ сервера), таймаут 600–1800 секунд (запись до часа на процессоре распознаётся долго), цена 0.
- Затем в блоке «Движок» нажмите «Выбрать движок модуля: оба» или «только распознавание». «Только текст» оставляет распознавание штатному движку Битрикс24.
- Запись до 64 МБ модуль держит в памяти: на хосте портала `memory_limit` PHP от 512M. «Проверить и включить» поднимает пределы записи ядра CRM до 2 часов и 64 МБ.
- Сервер, который умеет принимать части записи (поля `offset`, `max_duration`, ответ `next_offset`), получает длинные записи по 10 минут. Сервер без этих полей получает запись целиком.
- Ответ «речь не обнаружена» (HTTP 422, код `no_speech`) модуль считает звонком без речи, а не ошибкой. Порог отсечения тишины настраивается в самом сервере.

## Текст (vLLM, Ollama, LocalAI)

- Направление «Текст»: адрес сервера с `/v1` (у Ollama — `http://127.0.0.1:11434/v1`, у vLLM — `http://127.0.0.1:8000/v1`; порт зависит от вашего запуска), модель — имя, которое сервер принимает в поле `model`, ключ — если сервер его требует (часть серверов принимает любое значение, а часть — без ключа).
- Цены — 0, если сервер ваш; иначе задайте цены вручную: у своих адресов цен каталога нет.
- Если сервер не понимает `response_format`, модуль повторяет запрос без него и разбирает JSON из ответа сам. Отключить рассуждения модели можно в «Доп. параметры модели текста» (JSON-объект).

## Адрес на 127.0.0.1

Сервер ставьте на тот же хост, что и веб-сервер портала, а порт публикуйте только на `127.0.0.1`: сервер без ключа распознаёт и отвечает кому угодно. Запросы к приватным адресам из настроек модуль разрешает: адрес задаёт администратор. Не открывайте порт сервера в интернет без ключа и TLS.

## Когда данные не должны уходить наружу

- Записи и тексты уходят только на адрес из настроек направления. Свой сервер в своей сети — данные остаются у вас.
- Проверьте каждое направление: «Распознавание», «Текст», «Анализ сделок», «Чат AI-помощника». Пустое направление берёт общий адрес, а тот по умолчанию — `https://api.openai.com/v1`. В «Расходе и включении», блок «Куда уходят запросы», видно адрес каждого направления.
- Свой адрес без своего ключа ключ общего адреса не получает: ключ откатывается только вместе с адресом.
- Модель для работы AI-агента и помощника выбирайте с тем же правилом: наружу уходит всё, что вы направили облачному провайдеру.

## Проверка

См. [examples/curl-check.md](examples/curl-check.md): запрос к серверу проверяет ответ до настройки модуля. Затем в «Расходе и включении» нажмите «Проверить и включить».
