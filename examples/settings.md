# Наборы настроек (без ключей)

«Общие настройки» shef.toolsai, вкладка «API». Ключи вписывайте в поля ключей сами, в репозитории их нет. Сначала у направлений выберите «OpenAI-совместимое API» вместо «Заглушка».

## 1. Всё у DeepSeek, распознавание у OpenAI

| Направление | Провайдер | Модель | Ключ |
|---|---|---|---|
| Текст | DeepSeek | основная (`deepseek-flash`) | ключ DeepSeek |
| Распознавание | ChatGPT (OpenAI) | `whisper-1` или `gpt-4o-mini-transcribe` | ключ OpenAI |

Движок: «Выбрать движок модуля: оба».

## 2. Распознавание на своём сервере, текст у облачного провайдера

| Направление | Значение |
|---|---|
| Распознавание | Свой адрес `http://127.0.0.1:8000/v1`, модель — имя на сервере, ключ пусто, таймаут 1800, цена 0 |
| Текст | любой провайдер каталога, модель, его ключ |

Записи звонков остаются у вас, наружу уходит только текст.

## 3. Всё у себя

| Направление | Значение |
|---|---|
| Распознавание | `http://127.0.0.1:8000/v1`, цена 0 |
| Текст | `http://127.0.0.1:11434/v1` (Ollama) или адрес vLLM, имя модели с сервера, цена 0 |
| Анализ сделок, Чат AI-помощника | пусто (повторяют «Текст») |
