# Как актуализировать каталог

Для того, кто обновляет страницы провайдеров. Идти по порядку, ничего не додумывать: каждый факт берётся из источника ниже и проверяется живым запросом, где это возможно.

## Правила содержания

- Только актуальные модели. Устаревшие и отключаемые не упоминаются совсем.
- Тексты в настоящем времени, простыми словами, для человека, который подключает модель. Без «теперь», «больше нет», «перенесено».
- Без цен, без сравнения с другими сервисами, без адресов серверов, путей стенда и ключей.
- Ключ показывать маской: `vibe_api_a1b2****************z9y8`. Живые ключи из документации провайдеров не копировать.
- Названия и пути интерфейса модуля писать так, как они в модуле: «Общие настройки → вкладка «Движок» / «Провайдер»».
- Каждая страница провайдера заканчивается датой сверки и тем, чем сверяли (пробный запрос или документация).

## Где смотреть, по провайдерам

### DeepSeek
- Модели и контекст: `GET https://api.deepseek.com/models` с ключом (поля `context_window`, `max_output_tokens`, `input_modalities`).
- Страница цен и возможностей: https://api-docs.deepseek.com/quick_start/pricing — открывать с переходом по редиректу.
- Проверка ответа: пробный запрос на `https://api.deepseek.com/v1/chat/completions`.

### BitrixGPT Вайбкод
- Документация лежит файлами Markdown: `https://vibecode.bitrix24.tech/docs-content/<раздел>.md`. Читать:
  - `ai.md` — обзор AI Router, быстрый старт, список разделов;
  - `ai/pricing.md` — цены: `prompt` и `completion` за 1 млн токенов, `cachedPrompt` (`null` — кэш по цене входа), `perMinute`, `perCall`, всё в Vibes; чем платится вызов: квота портала или баланс;
  - `ai/consumption.md` — расход и квота;
  - `ai/models/lifecycle.md` — устаревание моделей, заголовки `Deprecation` и `X-Model-Replacement`;
  - `ai/audio.md` — распознавание речи.
- Список разделов: https://vibecode.bitrix24.tech/docs. Страница моделей: https://vibecode.bitrix24.tech/ai-models.
- Живой список с ценами и контекстом: `GET https://vibecode.bitrix24.tech/v1/models` с личным ключом (принимаются `Authorization: Bearer` и `X-Api-Key`).
- Что проверять каждый раз: какие модели в `GET /v1/models`; какие бесплатны (идут из AI-квоты портала) и какие платные; не объявлено ли отключение (смотреть заголовки ответа и страницу `lifecycle`).
- Модель распознавания: `bitrix/bitrixgpt-5.6-transcribe` (Whisper выводится с платформы с 16.11.2026).
- Пробный запрос: `POST /v1/chat/completions`; в `usage` смотреть `cached_tokens`.

### hoster AI studio
- Только документация: https://hoster.by/service/cloud/ai/ и справка https://hoster.by/help/hoster-ai/ (как подключить услугу, как подключиться к модели по API).
- Адрес API: `https://ai.hoster.by/v1`. Список моделей без ключа не отдаётся (ошибка 400): имена брать из кабинета.
- На справочной странице может быть опубликован пример ключа: не копировать.

### Яндекс (Yandex AI Studio)
- Только документация: список моделей https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models.
- Адрес API: `https://ai.api.cloud.yandex.net/v1`; имя модели `gpt://ID_КАТАЛОГА/имя`.
- Роль сервисного аккаунта: `ai.languageModels.user`.

## Что сверять в самом модуле

Каталог провайдеров модуля лежит в репозитории модуля (`lib/provider/presets.php`, список `CATALOG`). Сверять по ветке `main` на GitHub, а не по рабочей копии: копия может отставать. В каталоге модуля нет моделей «Своего адреса»: они подключаются вручную, и расход по ним не считается, пока не вписаны цены направления.

## Как искать, чтобы не ошибиться

1. Сначала живой запрос (если есть ключ у владельца), потом документация, потом страница провайдера. Данные из страницы без запроса помечать «по документации».
2. Для Вайбкода читать Markdown-файлы документации, а не страницу в браузере: страница отдаёт много служебного кода.
3. Цены в Vibes считать за 1 млн токенов (это написано в `ai/pricing.md`), 1 Vibe — один российский рубль. Цены на странице провайдера и в API могут отличаться от тарифа для клиента: сверять с документацией.
4. Бесплатная модель у Вайбкода — не значит бесплатная всегда: она идёт из AI-квоты портала.
5. Контекст и возможности (картинки) брать из `GET /models` провайдера, а не из памяти.
6. Курсы валют только по Нацбанку Республики Беларусь, а не по ЦБ РФ. Сайт Нацбанка может не открываться из некоторых сетей: тогда искать курсы на дату в поиске, брать два числа (доллар к белорусскому рублю и 100 российских рублей к белорусскому рублю) и называть источник.
7. Расход по ключу провайдера смотреть в его кабинете за нужные дни; у DeepSeek на странице использования видно вход из кэша, вход без кэша и выход по дням.

## Как вносить правки

1. Ветка от `main`, правки по страницам провайдеров, запись в `CHANGELOG.md` под «Не выпущено».
2. Проверка текстов: нет устаревших моделей, нет цен, нет живых ключей, нет адресов серверов.
3. Pull request; описание заканчивается строкой «🤖 Generated with [Claude Code](https://claude.com/claude-code)». В коммитах без строки о модели.
4. Ссылки между страницами относительные и проверены.
